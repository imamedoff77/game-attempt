# Faza 5: Online 1v1 (plan və vəziyyət)

> Ümumi plan: `GAME_PLAN.md`. Əsas (lockstep, relay server, qopma/yenidən qoşulma) Faza 1-də hazırdır; burada onun üstünə oyun qaydaları və hesab gəlir.

## İşlər

- [x] 5.1 (2026-11-05) **Onlayn matçda Armory.** Protokol 2: `CreateRoom`/`JoinRoom` oyunçunun Armory səviyyələrini (hər vahid növü üçün 1 bayt) göndərir, server onları təmizləyir (`NetKits.Clean`: maksimumdan böyük kəsilir, çatışmayan 0) və hər iki oyunçuya `MatchStart`/`MatchResume` ilə **hər iki komandanın** dəstini bildirir. Hər iki telefon (və bot) eyni bonusları qurur, ona görə hash eyni qalır. Testlər: `GameServerTests.BothPlayersGetBothArmoryKits...`, `LockstepTests.Kits_...`. Telefon + bot ilə 600+ tick sinxron (Jeep səviyyə 3).
  - **Boşluq:** server hələ oyunçunun *həqiqətən* bu səviyyələrə sahib olduğunu yoxlamır (oyunçu 5-5-5 deyə bilər). Düzəliş: oyunçu hesab tokenini otağa göndərir, relay server hesab serverindən profil Armory-sini oxuyub `min(iddia, hesab)` qəbul edir. Pullu alışdan əvvəl mütləq (Faza 6).
- [x] 5.2 (2026-11-05) **Hesab tokeni ilə otağa giriş.** Protokol 3: `CreateRoom`/`JoinRoom` hesab sessiya tokenini daşıyır (yalnız server görür, rəqibə getmir). Oyun serveri `GAME_ACCOUNT_URL` + `GAME_ACCOUNT_KEY` ilə başladılanda yalnız girişli oyunçuları qəbul edir (`RejectReason.NotSignedIn`), token hesab serverinin daxili endpoint-i `POST /v1/internal/verify-session` ilə yoxlanır (`Account__InternalKey`), Armory iddiası hesabda saxlanan səviyyə ilə məhdudlaşır, eyni hesab iki oturacağı tuta bilmir (`SameAccount`). Hər iki dəyişən boşdursa server açıqdır (inkişaf: qonaqlar, iddia olunan Armory). Testlər: GameServer 21, AccountServer 36. Telefon + hesab serveri + oyun serveri + bot ilə yoxlanıb.
  - **Qalan boşluq:** hesabdakı Armory də telefondan sinxronlaşır (güvənilən məlumat), yəni indi yalnız iddianı hesaba bağlayırıq. Həqiqi yoxlama kreditlərin və alışların serverdə aparılmasını tələb edir (Faza 6-dan əvvəl).
- [x] 5.3 (2026-11-05) **Rəqib tapma və reytinq.** Protokol 4: `QuickMatch` (növbəyə gir), `Queued`, `LeaveQueue`, `MatchInfo` (hər iki reytinq), `ReportResult(winnerTeam)`, `RatingUpdate`. Oyun serveri matçı hesab sistemindən tanınan reytinqə görə cütləyir (fərq ≤ 100 + saniyədə 50; gözlədikcə pəncərə böyüyür; eyni hesab öz-özü ilə yox; tərəfi yazı-tura ilə). Nəticə: oyunçular yalnız iddia edir (`ReportResult`); server relay-in saxladığı komanda jurnalını eyni deterministik simulyasiya ilə **təkrar oynadıb** (`Replay`, `MatchReferee`) qalibi özü müəyyən edir, uyğun gəlməyən iddia nəzərə alınmır; qalıcı çıxan (60 san. grace) məğlub sayılır (walkover), amma təkrar oynatma matçın başqa cür bitdiyini göstərirsə qalib odur. Hesab serveri: `users.rating/rated_games/rated_wins`, `rated_matches` (bir matç bir dəfə), `POST /v1/internal/report-match`, `Rating.cs` (Elo, K 32→20). Unity: Online səhifəsində reytinq və "Find opponent (ranked)", axtarış ekranı, nəticə kartında reytinq dəyişikliyi, Profile-da reytinq. Dost otaqları (kodla) reytinqsizdir. Testlər: sim-core `RatingTests`, GameServer `RankedTests` (11), AccountServer `RatingEndpointTests` (4). İki bot + real PostgreSQL ilə yoxlanıb (walkover: 1016/984).
  - Saxtakarlığa qarşı əsas hissə (nəticənin serverdə yoxlanması) bununla hazırdır; 5.5-də qalanlar: server vaxtı, çat, hesabat/şikayət.
- [x] 5.4a (2026-11-05) **Onlayn menyu.** Ana menyuda "Online": girişsiz oyunçuya "Sign in" + Account düyməsi; girişli oyunçu "Create room" (böyük otaq kodu göstərilir) və ya kodu yazıb "Join". Matç menyudan başlayır, oyunda "Leave" düyməsi, nəticə kartı (Victory/Defeat → Main menu). Server ünvanı `Assets/Resources/gameserver.txt` ("host:port", git-də yoxdur). Telefon + serverlər + bot ilə yoxlanıb.
- [x] 5.4b (2026-11-05) **Təslim olmaq və rəqib getdi.** Yeni `SurrenderCommand` (əmr kodu 10, hash-ə yalnız istifadə olunanda daxil olur): onlayn matçda "Surrender" düyməsi (3 saniyəlik "Sure?" təsdiqi) təslim olan komandanı məğlub sayır. Rəqib bağlantısı 60 saniyə bərpa olunmasa server qalan oyunçuya `Reject(OpponentGone)` göndərir və klient Victory (walkover) göstərir. Testlər: `MatchRulesTests` (kodek, hash), `ServerTests.ASurrender_...`, grace testi OpponentGone yoxlayır. Telefonda yoxlanıb (Surrender → DEFEAT; bot çıxır → 60 s sonra VICTORY).
- [x] 5.4c (2026-11-05) **Onlayn açılması və nəticələr.** Onlayn oyun kampaniyanın ilk 3 missiyası qazanılandan sonra açılır (`Campaign.OnlineUnlockMission`, `CampaignProgress.OnlineUnlocked`; dev qurulmalarında kilid yoxdur). Reytinqli nəticə serverdə sayılır (5.3). Quick (reytinqli) matçlar **Armory bonusları olmadan** oynanır: hamı bərabər başlayır və müştərinin saxtalaşdıra biləcəyi Armory boşluğu ranked üçün bağlanır; dost otaqları Armory ilə qalır.
- [x] 5.5a (2026-11-05) **Sürətli çat.** Protokol 5: `Chat(preset)` / `ChatFrom(team, preset)`, 8 hazır ifadə (`ChatPresets`, mətnlər `chat.N`), sərbəst mətn yoxdur (moderasiya lazım deyil), server saniyədə 1-dən tez ifadələri atır. Oyun içində "Chat" düyməsi və ifadə paneli, rəqibin ifadəsi 4 san. göstərilir. Telefonda panel yoxlanıb.
- [x] 5.5b (2026-11-05) **Saxtakarlığa qarşı:** ranked nəticəsi relay jurnalının təkrar oynadılması ilə təsdiqlənir (5.3-ə bax); balans verisi (`gamedata.json`) fərqli olan müştəri ranked-a buraxılmır.
- [x] 5.5c-1 (2026-11-05) **Server vaxtı.** Hər hesab serveri cavabının `Date` başlığı oyunun saatını düzəldir (`TrustedClock` sim-core-da, `GameClock` Unity-də): gündəlik mükafat günü və booster müddəti telefonun saatına yox, serverin vaxtına görə hesablanır; saat geri çəkilməklə qazanc yoxdur (vaxt heç vaxt geri getmir), serverdən cavab gəldikdən sonra telefon saatını dəyişmək vaxtı tərpətmir. Girişsiz (qonaq) oyunçu telefon saatından istifadə edir, amma o da geri çəkilə bilməz. Testlər: `TrustedClockTests` (6). **Qalan boşluq:** oflayn rejimdə saatı irəli çəkmək növbəti server cavabına qədər işləyir; kreditlər hələ müştəri tərəfindədir (`STORE_SETUP.md`-də "Known limits").
- [ ] 5.5c-2 Oyunçu hesabatı/şikayət: çat yalnız hazır ifadələrdir, nəticələr serverdə yoxlanır, ona görə yalnız təhqiramiz ad (displayName) qalır. Ad üçün hesabat və söyüş filtri buraxılışdan əvvəl (Faza 8) edilir.
